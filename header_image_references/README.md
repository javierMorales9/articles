# Header Image References

These images define the house style for article header images.

Use them as visual references when generating `postN/header_image.png` files:

- `two_fat_guys_fighting_over_donut.webp`: conflict over a shared resource; useful for concurrency, contention, race conditions, and hidden state bugs.
- `robot_singing_opera.webp`: artificial performer accepted by a real audience; useful for AI-assisted writing, automation that feels human, and creative tooling.
- `guy_bulb_idea.webp`: a concrete idea becoming valuable; useful for business ideas, leverage, pricing, and early revenue posts.
- `vr_gameplay.webp`: immersive attention and addictive interaction; useful for UX, engagement loops, and product pull.
- `boring_meeting.webp`: dead corporate presentation; useful for communication, presentations, storytelling, and audience attention.

The goal is not to copy these exact scenes. The goal is to reuse the visual language:

- polished pixel art;
- horizontal editorial banner;
- expressive characters;
- one clear visual metaphor;
- enough environmental detail to make the scene feel specific.
